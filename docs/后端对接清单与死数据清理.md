# 后端对接清单与死数据清理

> 日期：2026-11-06
> 范围：`app/src/main/java`。结论来自 Repository → Api 的实际调用关系，不以后端文档或旧注释为准。

## 一、已经接后端的功能

| 模块 | 代表入口 | Repository / Api | 说明 |
|---|---|---|---|
| 登录 / 注册 / 验证码 / 改密 | Login、Register、Settings | `AuthRepository` → `AuthApi` | 全部走 `/auth/*` |

| 课程列表 / 详情 / 播放地址 | 首页、课程详情、播放器 | `CourseRepository` → `CourseApi` | 播放地址取详情里的 `videoUrl` |

| 文章列表 / 详情 / 发布 / 删除 / 我的发布 | 社区、文章详情、我的发布 | `ArticleRepository` → `ArticleApi` | 编辑/撤回/举报后端未提供 |

| 文件上传 | 头像、图片 | `FileRepository` → `FileApi` | — |
| 首页轮播 | 首页 | `BannerRepository` → `BannerApi` | — |
| 短视频 | 视频 Tab | `VideoViewModel` → `VideoApi` | — |

## 二、本次清理掉的遗留死数据

| 位置 | 处理 |
|---|---|
| `data/demo/Preview.kt` | 删除。`preview()` / `contentPreview()` 已无调用点 |
| `build.gradle.kts` | 删除 `UI_PREVIEW` / `CONTENT_PREVIEW` 编译开关及 `-PuiPreview` 相关分支 |
| `data/demo/DemoData.kt` | 581 行 → 156 行。删除已接后端模块的样例：分类树、课程列表/详情、文章详情、评论/回复、个人资料、收藏/点赞/历史、笔记、课程评分 |
| 课程评分 | 删除 `DemoData.ratings/rateResult`、`CourseRepository.rateCourse/getRatings`、`RatingDto`；改接 `RatingRepository`。后端只返回平均分/人数，没有评价列表，因此移除假的「全部评价」和评论输入框 |
| 搜索 | 删除 `DemoData.searchResult`；`SearchRepository.searchPage` 改为按类型调 `/search/post`、`/search/course`，分类页无关键词时走课程列表 |
| 搜索页 | 删除写死的搜索历史（Java/Python/机器学习…）；后端没有搜索历史接口 |
| 课程详情「最近点赞」 | 删除写死的张/李/王/赵/陈头像，只保留真实 `likeCount` |
| 社区个人主页 | 删除写死的昵称「小红」、简介、性别「男」和粉丝头像墙；他人资料改为中性占位 |
| 签到积分 | 删除拉取失败时回退的本地兑换档位 `ExchangeResultDto.OPTIONS` |
| 学习数据页 | 删除写死的 45 分钟 / 7 天 / 3 门课 / 12 篇笔记 / 5 个待办和柱状图，改为「暂未接入后端」空态 |
| 学习路径页 | 整页是写死路径且无入口，删除页面、路由和 NavHost 注册 |
| 广告位仓库 | 删除从未被调用的 `getAppConfig()` 及其 `DemoData.appConfig` |


结果：`BUILD SUCCESSFUL`，单元测试通过。

> 注意：本机 `workspace-write` 沙箱会让 Java 把所有项目目录判成不可写，Gradle 9.5 因此在普通沙箱下无法启动；上面的构建是在完整访问权限下执行的，与业务代码无关。
