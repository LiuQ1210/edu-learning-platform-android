### 广告（只预留位，不接 SDK）

**原则**：客户端现在只在布局里预留广告位容器，不引入任何广告 SDK 依赖。后期接 Taku 聚合时，统一往预留位里填。

需要预留的位置：

| 位置 | 形式 | 说明 |
|---|---|---|
| 开屏 | 启动后 1-2 秒广告位 | `SplashScreen` 里留一个可替换的 ViewStub 区域 |
| 首页信息流 | 第 5 条课程卡片后插一条横幅位 | `HomeScreen` 课程列表里留一个 `item { AdSlot() }` |
| 播放页暂停 | 暂停时底部横幅 | `PlayerScreen` 底部控制条上方留一个广告位 |
| 社区列表 | 第 3 条帖子后插一条 | `CommunityScreen` 列表里留位 |

**现在做的事**：
- 写一个空的 `AdSlot` Composable（`ui/ad/AdSlot.kt`），接受 `slotId` 参数，内部先返回空 Box 占位
- 在上述位置插入 `AdSlot(slotId = "splash"/"feed_home"/"player_pause"/"feed_community")`
- 后期接 Taku 时只改 `AdSlot` 内部实现，业务页面一行不动

**现在不做的事**：
- 不引入 Taku SDK 依赖
- 不做广告点击统计、不做广告屏蔽逻辑
- 不做广告跳过倒计时（Taku SDK 自己带）

## 风险与砍范围

**阶段三按下面顺序砍**：

1. 智能搜索先砍（基础搜索够用）
2. 学习路径先砍（产品方向未定）
3. 学习进度可视化降级为"课程详情显示已学时长"，不做章节树
4. 学习记录先做今日时长 + 连续天数，不做周曲线

**不要砍的**：广告位预留（后期接 SDK 时再改布局成本高）、推荐流接口设计（后端要先定字段）。
