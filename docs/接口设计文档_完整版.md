# 智能广告基座（学习平台）— 接口设计文档

> 贵州慧科未来科技有限公司
>
> **统一规范：**
> - URL 前缀：`/api/v1`，短横线命名
> - 通信协议：HTTPS + JSON，Content-Type: application/json
> - 成功码：`0`
> - 统一响应体：`{ "code": 0, "message": "success", "data": {}, "timestamp": 1725953287000, "requestId": "uuid" }`
> - 分页参数：`pageNum`（默认1）/ `pageSize`（默认20，最大100），返回 `{ total, list }`
> - 鉴权：请求头 `Authorization: Bearer <accessToken>`，除白名单接口外全部需要登录
> - 幂等：写操作（发布/签到/收藏/下载等）需携带 `X-Idempotent-Token: <UUID>`，防重复提交
> - 链路追踪：请求头 `X-Trace-Id: <TraceId>`，响应体返回 requestId
> - 字段命名：接口 JSON 出入参用 camelCase，数据库用 snake_case
>
> **核心机制**：双Token（accessToken+refreshToken）、评论游标分页、幂等Token、课程三层结构+VOD播放凭证、搜索热词、统一多态评论/收藏/点赞/分类、分类多级树形、评论举报、课程独立评分、连续签到天数、评论三级楼中楼（root_id+parent_id）、文件统一上传、手机号/邮箱双通道注册。
>
> **匿名白名单接口**（无需Token）：注册、登录、刷新Token、微信登录、发送验证码、分类树、内容搜索、搜索热词、课程详情、文章详情、APP配置、广告位配置。其余全部需要登录。

## 二、认证模块（11个接口）

### 2.1 发送验证码

- **URL**: `POST /api/v1/auth/send-code`
- **鉴权**: 否（匿名）
- **说明**: 发送手机/邮箱验证码，60秒内限发一次，每日上限可配置

**请求参数（Body）：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| target | string | 是 | 手机号或邮箱 |
| targetType | int | 是 | 1-手机号 2-邮箱 |
| scene | string | 是 | 业务场景：register/login/reset_password/change_phone/change_email |

**响应 data**: `{ "expireSeconds": 300 }`

---

### 2.2 密码注册

- **URL**: `POST /api/v1/auth/register`
- **鉴权**: 否（匿名）
- **幂等**: 需要 `X-Idempotent-Token`
- **说明**: 手机号/邮箱 + 密码 + 验证码注册，注册成功签发双Token

**请求参数（Body）：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| account | string | 是 | 手机号或邮箱，全局唯一 |
| accountType | int | 否 | 1-手机号（默认）2-邮箱 |
| password | string | 是 | 密码（6-20位，需同时包含字母和数字） |
| code | string | 是 | 对应通道的 6 位验证码 |
| nickname | string | 否 | 昵称，不传则自动生成 |
| email | string | 否 | 邮箱。`accountType=2` 时可不传（等于 `account`） |

**响应 data**:

```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
  "refreshToken": "a1b2c3d4e5f6...",
  "expiresIn": 7200,
  "user": {
    "userId": 1001,
    "username": "user_1001",
    "nickname": "小明",
    "avatar": "",
    "phone": "138****0000"
  }
}
```

**错误码**: 1001验证码错误 / 1002验证码过期 / 1008手机号已被注册 / 1009邮箱已被注册 / 400参数错误

> **落库规则**：`accountType=1` 时 `account` 写入 `user.phone`，`email` 列写 `NULL`；`accountType=2` 时 `account` 写入 `user.email`，`phone` 列写 `NULL`。未使用的一列必须写 `NULL` 而非空串（唯一索引允许多个 `NULL`，只允许一个 `''`）。邮箱地址禁止写入 `phone` 列（`VARCHAR(20)` 装不下，会截断或报错）。
>
> **username 处理**：注册请求不含 `username`，服务端生成 `user_{user_id}` 后回填，用户不可自定义。登录标识为手机号或邮箱。

---

### 2.3 密码登录

- **URL**: `POST /api/v1/auth/login`
- **鉴权**: 否（匿名）
- **说明**: 账号密码登录，连续5次失败锁定15分钟

**请求参数（Body）：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 用户名 / 手机号 / 邮箱（三选一命中） |
| password | string | 是 | 密码 |

**响应 data**: 同注册（accessToken + refreshToken + user）

**错误码**: 1004密码错误 / 1005账号不存在 / 1007账号已锁定

---

### 2.4 刷新Token

- **URL**: `POST /api/v1/auth/refresh`
- **鉴权**: 否（匿名，用refreshToken换）
- **说明**: accessToken过期后，用refreshToken换取新的双Token（旧refreshToken作废，轮转）

**请求参数（Body）：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| refreshToken | string | 是 | 刷新令牌 |

**响应 data**: `{ "accessToken": "...", "refreshToken": "...", "expiresIn": 7200 }`

**错误码**: 1003 refreshToken无效/已过期/已作废

---

### 2.5 登出

- **URL**: `POST /api/v1/auth/logout`
- **鉴权**: 是
- **说明**: 作废当前refreshToken，accessToken随过期自动失效

**请求参数（Body）：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| refreshToken | string | 是 | 当前refreshToken |

**响应 data**: `{}`

---

### 2.6 微信登录

- **URL**: `POST /api/v1/auth/wechat-login`
- **鉴权**: 否（匿名）
- **说明**: 前端获取微信code，后端换openid。已绑定则直接登录；未绑定则创建临时账号，返回1010需绑定手机号

**请求参数（Body）：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| code | string | 是 | 微信授权code |

**响应 data**:
- 已绑定：同登录（双Token + user）
- 未绑定：`{ "needBindPhone": true, "tempToken": "xxx" }`

**错误码**: 1010需绑定手机号 / 1011平台参数不合法

---

### 2.7 微信登录绑定手机号

- **URL**: `POST /api/v1/auth/wechat-bind-phone`
- **鉴权**: 否（匿名，用tempToken）
- **说明**: 微信新用户绑定手机号完成注册

**请求参数（Body）：**

| 字段 | 类型 | 必填 | 说明 |

| tempToken | string | 是 | 微信登录返回的临时令牌 |
| phone | string | 是 | 手机号 |
| code | string | 是 | 短信验证码 |
| nickname | string | 否 | 昵称 |

**响应 data**: 同注册（双Token + user）

---

### 2.8 绑定第三方账号（已登录用户）

- **URL**: `POST /api/v1/auth/bind-third-party`
- **鉴权**: 是
- **说明**: 已登录用户绑定微信/QQ等第三方账号

**请求参数（Body）：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| platform | string | 是 | wechat/qq/weibo |
| code | string | 是 | 第三方授权code |

**响应 data**: `{ "bound": true }`

**错误码**: 1012第三方账号已绑定

---

- **说明**: 解绑指定平台第三方账号

**Query参数**:

## 十五、文件上传模块（3个接口）

### 15.1 上传文件

- **URL**: `POST /api/v1/files/upload`
- **鉴权**: 是
- **幂等**: 需要 `X-Idempotent-Token`
- **Content-Type**: `multipart/form-data`
- **说明**: 统一上传入口。服务端校验 MIME 与魔数、按 `scene` 归档路径、生成唯一文件名，返回可直接落库到 `*_url` 字段的公网访问地址

**请求参数（multipart form-data）：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| file | file | 是 | 文件本体，字段名固定为 `file` |
| scene | string | 是 | 业务场景，取值见下表 |

**scene 取值与约束：**

| scene | 用途 | 落库位置 | 允许 MIME | 大小上限 |
|---|---|---|---|---|
| avatar | 用户头像 | `user.avatar` | image/jpeg, image/png, image/webp | 2 MB |
| article_cover | 文章封面 | `article.cover_url` | image/jpeg, image/png, image/webp | 5 MB |
| article_image | 文章正文内嵌图 | 无（正文 HTML 内） | image/jpeg, image/png, image/webp, image/gif | 5 MB |
| note_image | 笔记插图 | 无（正文内） | image/jpeg, image/png, image/webp | 5 MB |
| checkin_photo | 拍照签到 | `sign_record.photo_url` | image/jpeg, image/png | 5 MB |
| course_cover | 课程封面（后台） | `course.cover_url` | image/jpeg, image/png, image/webp | 5 MB |
| resource | 课程配套资源 | `resource.file_url` | 见 12.1 | 100 MB |

**响应 data**:

```json
{
  "fileId": "a1b2c3d4e5f6",
  "url": "https://cdn.example.com/avatar/2026/02/18/a1b2c3d4e5f6.jpg",
  "fileName": "avatar_20260218.jpg",
  "fileSize": 184320,
  "mimeType": "image/jpeg",
  "width": 512,
  "height": 512,
  "scene": "avatar",
  "createTime": "2026-02-18 14:32:10"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| fileId | string | 是 | 文件唯一标识，删除时使用 |
| url | string | 是 | **公网可访问的完整 URL（永久直链，不带签名参数）** |
| fileName | string | 是 | 服务端生成的文件名 |
| fileSize | long | 是 | 字节数 |
| mimeType | string | 是 | 服务端识别出的真实 MIME（不信任客户端声明） |
| width | int | 否 | 图片宽（px），非图片返回 0 |
| height | int | 否 | 图片高（px），非图片返回 0 |
| scene | string | 是 | 回显请求的 scene |
| createTime | string | 是 | 上传时间 |

**错误码**: 9101文件类型不允许 / 9102文件超过大小上限 / 9103文件内容为空 / 429上传限流（同用户20次/分钟）/ 500存储服务异常

> **客户端约定**：上传前本地压缩（图片长边 ≤ 1600px、JPEG 质量 85）；字段名必须是 `file`；`scene` 必传；`url` 原样落库，不自行拼 CDN 前缀。

---

### 15.2 删除文件

- **URL**: `DELETE /api/v1/files/{fileId}`
- **鉴权**: 是（仅本人上传的文件，或管理员）
- **说明**: 头像/封面替换成功后调用，递减引用计数，归零后由定时任务清理存储文件

**响应 data**: `{}`

**错误码**: 403非本人上传 / 404文件不存在

---

### 15.3 上传与业务写入的分工

- 上传与业务写入是两步：先 `POST /files/upload` 拿到 `url`，再调 9.2 签到 / 7.3 发文章 / 3.2 改资料 / 10.2 建笔记把 `url` 带上
- 若第二步失败，`url` 仍在 `file_record` 中留有记录，可由客户端延迟调用 15.2 清理，或由定时任务扫描 `biz_id IS NULL AND create_time < NOW() - 24h` 的记录回收
- 同一 `scene` 内相同 `sha256` 的文件直接复用已有 `url`，`ref_count` 累加
