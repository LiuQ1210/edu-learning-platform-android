# App 配色方案

## 品牌色（深浅色共用）

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 Primary | `#3677EF` | 品牌蓝，按钮/链接/选中态 |
| 主色深 | `#2A5FD0` | 渐变末端、按压态 |
| 主色浅底 | `#DCE8FF` | 选中胶囊底 |
| 点缀黄 | `#F0B000` | 便利贴/警告 |
| 点缀红 | `#D04030` | 错误/告警 |
| 点缀青 | `#00B0C0` | 成功/已完成 |
| 点缀粉 | `#F0B0B0` | 已收藏/柔性状态 |

## 浅色模式（奶油渐变底）

| 用途 | 色值 |
|---|---|
| 页面背景 | `#F7F9FC` |
| 卡片 Surface | `#FFFFFF` |
| 次表面 | `#F0F3F8` |
| 主文字 | `#1A1A1A` |
| 次文字 | `#666666` |
| 提示文字 | `#999999` |
| 分隔线 | `#EEEEEE` |
| 渐变顶 | `#FFFFFF → #FFFBF2 → #F8F0ED → #FDF5F5 → #FFFFFF` |
